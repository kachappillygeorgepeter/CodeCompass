# Code Compass

Code Compass is a lightweight browser extension that helps you understand highlighted code snippets instantly.

## Project Structure

```
code-compass/
├── backend/          ← Vercel serverless function
│   ├── index.js
│   ├── package.json
│   └── vercel.json
└── frontend/         ← Chrome extension
    ├── manifest.json
    ├── icons/
    └── src/
        ├── background/
        ├── content/
        ├── options/
        └── shared/
```
